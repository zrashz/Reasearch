# Connected development run

This update adds two independent workflows. It does not replace the earlier V0–V3 controller or make a final model selection.

1. `connected_claim_runner_v1.py` loads existing train:14460 E2 evidence, checks source identity and table correspondence, runs exactly one pinned Qwen generation, parses one explicitly scoped assertion using a narrow literal sentence grammar, binds the exact method column and MAD row, then calls the installed scope guard. Outputs retain the prompt, raw generation, code/source hashes and decision. Unsupported wording is withheld. A numerical assertion can be Supported or Refuted; whole-summary scientific approval is always false. This is a source-specific, assistant-reviewed adapter, not a general automatic semantic verifier. No source labels or human evaluation inventory enter the prompt. It is a constrained claim-writing task, not unconstrained summary-writing quality evaluation.

2. `screen_remaining_v1.py` processes the remaining 270 queued training pairs through Europe PMC search and XML retrieval, checks exact DOI identity, saves raw XML and structural availability counts. Resume skips existing per-record results and verifies source hashes and settings. Errors remain review items; they are not exclusions. A new retry pass must use a separate output directory. No paper is automatically eligible. No images are downloaded, no gold labels are read, and no models are run by screening. Europe PMC coverage creates availability bias; publisher/PDF alternatives remain necessary. The first 30 prior screening records remain unchanged.

Tests: 17 new offline tests, including wrong method, outcome, benchmark, missing condition/units, extra unsupported sentences, ambiguous source, nonfinite numbers, XML identity mismatch and screening success without eligibility approval. An actual-source XML/derived-table CLI fixture was exercised without model inference. Live Qwen inference must be run in Colab. No performance score is claimed from software tests.

Persistent outputs: choose project/private/connected_claim_runs and project/private/eligibility_screening/.../remaining_public_screen_v1. Model weights require CPU RAM; avoid keeping another large model loaded concurrently. Do not rerun a live result directory: each live invocation must use a new timestamp. Do not overwrite failed generations; inspect them.

Remaining research work: reliable general claim extraction and semantic scope alignment; integration into the complete V0–V3 correction policy; visual adapter reliability; full eligibility and study grouping; independent finding inventories and reviewers; validation/frozen settings; held-out evaluation; reproducibility/report/GitHub. Today’s achievable engineering milestones are not completion of those experiments.
